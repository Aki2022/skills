# Dashboard Data Visualization

## チャート選択の原則（recommendation）

| 目的         | 推奨チャート                 |
| ------------ | ---------------------------- |
| 時間推移     | 折れ線                       |
| カテゴリ比較 | 横/縦棒                      |
| 構成比       | 積み上げ棒（項目少数のみ円） |
| 地理分布     | コロプレス地図               |
| 相関         | 散布図                       |
| 単一重要指標 | KPIカード（数値 + 前期比）   |

## 誤読防止（constraint）

- 棒グラフの数値軸は原則0起点。切る場合は明示する。
- 二重軸は極力避ける。使う場合は単位を明記。
- 過度な補間・3D・影で量の知覚を歪めない。
- 色覚多様性に配慮（色 + 形/ラベルの併用、識別しやすいパレット）。

## メタ情報（constraint）

各チャート/カードに **単位・対象期間・出典** を添える。`[自動]`（dashboard-meta）で存在確認。

# Dashboard Map

## 用途

地理的分布（自治体別の人口・財政指標など）を示すコロプレス地図・ポイント地図。

## 制約

- 凡例に階級区分と単位を明示する。
- 色階級は連続量に適したシーケンシャル、増減の対比にはダイバージングを使う。色覚配慮パレット。
- 出典・対象期間・境界データの版を明記する。

## 推奨

- 階級数は5〜7を目安（過剰な区分は誤読を招く）。
- 面積の大小による視覚バイアスに注意（小面積の重要地域が埋もれないよう補助表示）。

## データ注意

行政区域ポリゴン等の境界データはライセンス・版管理が必要。digital-agency plugin の references.md で管理し、
ライセンス承認前は実データを同梱・反映しない。

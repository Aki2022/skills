# HTML Responsive

## ブレークポイント目安（recommendation）

| 区分    | 幅の目安   |
| ------- | ---------- |
| mobile  | ~640px     |
| tablet  | 641–1024px |
| desktop | 1025px~    |

Plugin にブレークポイント指定があればそちらを優先する。

## 制約（constraint）

- 各区分で横スクロールが発生しない・要素が重ならない・テキストが切れない。
- タップ領域は十分な大きさ（44px 相当以上）を確保する。
- 画像は `max-width: 100%` 等で親幅を超えない。

## 自己点検

- コンテンツの優先順位がモバイルでも保たれているか（重要要素が折り畳みで埋もれないか）。

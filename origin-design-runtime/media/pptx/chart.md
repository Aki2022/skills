# PPTX Chart

## 制約

- チャートには単位・凡例・出典を明示する。
- 3D・過度な装飾を避け、データの誤読を招かない。
- 色は意味を持って使う（系列ごとに一貫、赤=悪/危険など慣習に反しない）。

## 推奨

- チャート種別はデータに合わせる:
  - 時系列 → 折れ線
  - カテゴリ比較 → 棒
  - 構成比 → 積み上げ棒（円グラフは項目が少ない時のみ）
- 1チャート1メッセージ。強調したい系列を色/太さで際立たせる。

## 自己点検

- 軸の起点・スケールが誤読を招かないか（棒グラフの縦軸は原則0起点）。
- ラベルが重なって読めなくなっていないか。

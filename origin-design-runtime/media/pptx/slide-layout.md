# PPTX Slide Layout

## レイアウト種別（目安）

| レイアウト       | 用途                              |
| ---------------- | --------------------------------- |
| タイトル         | 表紙・章扉                        |
| タイトル+本文    | 主張 + 箇条書き/図                |
| 2カラム          | 比較・Before/After                |
| 図表中心         | チャート/表を主役に、結論を上部に |
| セクション区切り | 章の切り替え                      |

## 制約

- スライドマスター/レイアウトを使う（pptx-master）。
- タイトル位置・本文領域・脚注領域を一貫させる。
- セーフマージン（端から一定の余白）を確保し、要素をスライド端に密着させない。

## 推奨

- 1スライドの情報ブロックは 3〜5 個までを目安に。
- 視線導線（左上→右下）に沿って結論→根拠を配置。

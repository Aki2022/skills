# PPTX Typography

## サイズ目安（constraint 下限あり）

| 役割             | サイズ目安 | 下限 |
| ---------------- | ---------- | ---- |
| スライドタイトル | 28–36pt    | —    |
| 本文             | 18–24pt    | 18pt |
| 注釈・出典       | 12–14pt    | 12pt |

`[自動]`（pptx-font-size）で本文/注釈の下限を PPTX XML から抽出して判定する。

## 制約

- 本文18pt・注釈12pt相当を下回らない（会場後方からの可読性）。
- フォントファミリは Plugin 指定（または Runtime デフォルト）に揃える。原則2種まで。

## 自己点検

- 和欧混植でベースライン・字間が破綻していないか。
- 太字/色による強調を使いすぎていないか。

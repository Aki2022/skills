# 正規化マッピング

取得した第三者 DESIGN.md を、design-runtime の内部形式へ写像する規則。**具体値はコピーせず、
抽象化した特性のみ**を各カテゴリに落とす。

| 内部カテゴリ     | 取り込む内容（抽象化）                             | 取り込まないもの                   |
| ---------------- | -------------------------------------------------- | ---------------------------------- |
| Visual Theme     | 全体の雰囲気・トーン（例: 親しみ / 信頼 / 先進）   | 具体的なブランド名の想起表現       |
| Color Roles      | 配色の**役割構成の考え方**（主/副/強調の使い分け） | 具体的なカラーコード（コピー禁止） |
| Typography       | 和文中心か・字間/行間の密度感                      | 固有フォント指定の丸写し           |
| Spacing / Layout | 余白の広さ・情報密度・グリッド感                   | ピクセル値の丸写し                 |
| Components       | UI表現の**傾向**（角丸/影/罫線の強弱）             | 固有コンポーネントの意匠コピー     |
| Iconography      | アイコンのテイスト傾向                             | 固有アイコンセットの再利用         |
| Motion           | 動きの有無・控えめさ                               | —                                  |
| Accessibility    | 配慮の観点                                         | —                                  |
| Content Tone     | 文体（敬体/常体・硬さ）                            | 固有のコピー文言                   |
| Do / Don't       | 一般化した原則                                     | 固有表現                           |
| Examples         | 「こういう方向性」の言語化                         | スクリーンショット/実装のコピー    |

## 出力

正規化結果は「参照メタ情報」として Context Composer に渡す（優先度6）。実際の色・フォント・
レイアウト値は自社/指定 Plugin（優先度3〜5）から採用する。差分（参照元 vs 自社）を成果物に説明する。

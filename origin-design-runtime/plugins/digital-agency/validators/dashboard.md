# Digital Agency Dashboard Validator

`media/dashboard` のルールに加え、デジタル庁「ダッシュボードデザインの実践ガイドブック」の
考え方を参考にした点検項目（出典は references.md）。

## 追加チェック

- 各KPI・チャートに **単位・対象期間・出典** が明示されているか（`[自動]` dashboard-meta）。
- チャート種別がデータに適合しているか（時系列=線 / 比較=棒 / 分布=地図）（`[自己点検]`）。
- 棒グラフの数値軸が原則0起点で、誤読を招くスケールでないか（`[自己点検]`）。
- 色が意味を持って一貫使用され、色覚多様性に配慮しているか（`[自己点検]`）。
- 行政区域ポリゴン等のデータを使う場合、ライセンス（国土数値情報規約）確認が済んでいるか
  （未確認なら使用しない）（`[自己点検]`）。
- 公式資料と誤認される表現になっていないか（`[自己点検]` brand-consistency と連動）。

## 不合格時

メタ情報欠落（単位/期間/出典）は必ず補う。ライセンス未確認データは使わない。

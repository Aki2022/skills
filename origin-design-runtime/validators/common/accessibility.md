# Accessibility Validator [自動 + 自己点検]

媒体横断のアクセシビリティ点検。媒体固有項目は各 media/plugin の validators を併用する。

## チェック項目

| 項目                                                      | 方式                  |
| --------------------------------------------------------- | --------------------- |
| コントラスト比が基準以上か                                | [自動]（contrast.md） |
| セマンティックな構造（見出し階層・ランドマーク）か        | [自動]（HTMLの場合）  |
| 画像・アイコンに代替テキストがあるか                      | [自動]（HTMLの場合）  |
| キーボードのみで操作・到達できるか                        | [自己点検]            |
| フォーカス表示が視認できるか                              | [自己点検]            |
| 色のみに依存した情報伝達をしていないか                    | [自己点検]            |
| 動き・自動再生に配慮があるか（prefers-reduced-motion 等） | [自己点検]            |

## 不合格時

`type: constraint` に該当する項目（コントラスト・ARIA 必須箇所）は Plugin 意匠より優先して修正する。

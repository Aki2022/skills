# Contrast Validator [自動]

生成物の色使用が WCAG コントラスト基準を満たすか検証する。

## 基準

- 本文テキスト（通常サイズ）: 前景/背景のコントラスト比 **4.5:1 以上**
- 大きい文字（18pt / 14pt太字相当以上）: **3:1 以上**
- UIコンポーネントの境界・状態表現: **3:1 以上**

## 検証方法

- HTML: 前景色/背景色のペアを抽出し、相対輝度からコントラスト比を計算して閾値判定する。
- 判定できない色指定（画像上テキスト、グラデーション）は `[自己点検]` に降格し、目視確認を促す。

## 不合格時

- 該当箇所と実測比を報告し、DESIGN.md/tokens の許容範囲内で前景または背景を調整する。
- Media Rule の `type: constraint`（コントラスト）は Plugin 配色より優先される（context-composer.md 優先度2）。

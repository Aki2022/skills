# Layout Validator [自己点検]

レイアウトの整列・余白・情報密度を点検する。

## チェック項目

- 要素が共通のグリッド/整列基準に沿っているか（左揃え・端揃えの乱れがないか）。
- 余白（マージン/パディング）が spacing トークンの倍数で一貫しているか。
- 情報密度が過剰でないか。1ブロックに詰め込みすぎていないか。
- 視線誘導（Z / F 型）と情報の優先順位が一致しているか。
- グリッド列数は Media Rule の `type: recommendation`。Plugin 指定があればそちらを優先（優先度3 > 5）。

## 不合格時

spacing トークンに丸め、整列基準を1つに統一する。密度が高い場合はセクション分割・余白追加で緩める。

# builder_brief.template.md — スライドビルダー共通ブリーフ（雛形）

③で各スライドを担当するビルダーサブエージェントへ渡す共通指示の雛形。デッキの `process/` に
`builder_brief.md` としてコピーし、パス等を実デッキに合わせて調整してから各ビルダーに読ませる。
「そのスライドの `mockup_NN.png` を読んだ者だけが実装できる」という③の原則を、正本の優先順位付きで
明文化するのが目的（テキストだけから組ませない）。

---

あなたは1枚のスライドの実装担当。**承認済み `mockup_NN.png` が構図の仕様書**であり、あなたの仕事は
`slides/sNN.js` を編集して、mockupの構図・視覚デバイスをネイティブPPTXとして忠実に再現すること。

## 正本の優先順位（迷ったらこの順）

1. **構図・視覚デバイス**（配置・列数・アイコン有無・バッジ・吹き出し・区切り線・強調色）= `mockup_NN.png`
2. **テキスト内容** = `outline.md` の該当スライド節（mockup内の文字は近似。転記せず outline の文言を使う）
3. **埋め込みスクショの内容** = `input/` 原本。mockupが別画面を描いていても原本を使い、構図・注釈だけmockupに合わせる
4. 数値・チャートは捏造禁止（実データチャートは専用スライドのみ・別途ネイティブ描画）。
   **例示チャート（実データが無い図）は空枠にせず「数値なしイメージ図」で描く**——棒・凡例・
   カテゴリラベルはネイティブ図形で描き、数値・%・目盛りは描かず右上に小さく「イメージ」と明記
   （空のグレー帯は未完成に見えて差し戻される。gotchas §12）

## API（共有 ctx / deck_helpers v3 経由。座標は全てpt・**960×540キャンバス**）

`T(text) / numUnit(数字+単位) / box / rct / arrow / homePlate / line / badge /
imgFit(inputスクショ) / imgPath(生成アセット) / chrome({title,keyMessage,tone}) /
source(txt) / speechBubble(吹き出し+尻尾)` と色トークン `C.*`。
（詳細は該当デッキの deck_helpers と `references/pptxgenjs-gotchas.md` §14 を参照）

- **title=tracker（名詞句or疑問形・14pt灰）、keyMessage は必ず1行（28pt・tone色）**。
  outline の文言をそのまま使い、勝手に主張文タイトルへ変えない
- **フッター・ページ番号・コピーライトは master が自動付与**——自分で置かない（二重表示）
- **下段に takeaway box・まとめ帯を作らない**（mockupに無いものを足さない。説明は右1/3箇条書き）
- 数字+単位は `numUnit()`（単位=数字の50%サイズ）。改行は文節境界に手動 `\n`。
  カード見出し・数値は align/valign を center/middle に明示
- **右1/3箇条書きのフォントは項目数でスケール**（一律14pt禁止・2026-07-16改訂）:
  2〜3項目=20pt / 4項目=18pt / 5項目以上=14pt。最重要の結論行はマーカーなし・太字の
  独立パラグラフに格上げ。右カラム下部の「白地＋黒細枠＋太字#44546A」示唆ボックスは
  許可（スライド全幅のtakeaway boxは引き続き禁止）。詳細は layout-grammar §8
- 吹き出しは自作せず `speechBubble()` を使う（尻尾の分離・継ぎ目は既知の2敗パターン。gotchas §10）
- 表は必ず `addTable`（枠線を図形で模造しない）

## アセット

- `asset_map.json` の「ファイル名→対象スライド」に従い、自分のスライドの割当アセットを mockup の位置に置く
- アセットは**正規化済み**（白背景透過・ライン画は#404040単色）。濃色セルに載せる場合は**白チップを敷いてから**重ねる
- 割当に無いアイコンが mockup にある場合は、勝手にファイル名を発明せず「不足アセット: <説明>」と報告する

## 制約

- 編集は自分の `slides/sNN.js` **1ファイルのみ**（entry・他スライド・mockup・outlineは変更禁止）
- ビルドは実行しない（並列担当者と衝突する）。構文チェックのみ: `node --check slides/sNN.js`
- テキスト量目安: ノード見出し8字・カード本文14字×2行・箇条書き40字×2行。CJKは**単語途中で改行しない**
- セーフマージン42pt（左右）。**本文・注記・出所の最下端は y≤500** に収める（source はヘルパ既定
  y=496。フッター帯 y≥512 は master 領域）。既知の描画罠は `pptxgenjs-gotchas.md` 参照
- チャートの軸ラベルは**箱幅≤バーピッチ**で設計し `wrap:false` を付ける（隣接ラベルの重なり・
  1文字縦折返しの防止。gotchas §11）

## 完了報告

実装した構図の要点（2-3行）／使用・不足アセット／mockupから意図的に変えた点と理由。

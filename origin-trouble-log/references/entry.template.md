  canon   必須。そのとき読んでいた横断正典の版。取り方:

          本文に散らばらせない。保管ルートの解決後パスも書かない

status は entry の frontmatter に追加しない。entry は発生時点の証拠として固定し、
triage_status / response_status / response_ids / status_basis / next_action は status ledger に置く。

secret は書く時点で値をマスクし構造を残す（Bearer <redacted> 等）。
会社ドメイン・顧客名・リポジトリ名はマスクしない
（どこで再発しているかを追えなくなると集積の目的が消える）。

frontmatter の `paths` はリポジトリ相対パスへ正規化する。

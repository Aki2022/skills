# Digital Agency Dashboard Example

自治体向け人口・財政ダッシュボードの参考構成（UC-01 に対応）。

## 画面構成（例）

```text
┌───────────────────────────────────────────────┐
│ タイトル + 対象期間 + 出典                        │
├───────────┬───────────┬───────────┬───────────┤
│ KPIカード  │ KPIカード  │ KPIカード  │ KPIカード  │  ← 総人口/増減/歳入/歳出 等
├───────────┴───────────┴───────────┴───────────┤
│ 時系列（折れ線）: 人口推移        │ 棒: 歳入内訳   │
├───────────────────────────────┴───────────────┤
│ 地図（コロプレス）: 地区別指標   │ フィルター/凡例 │
└───────────────────────────────────────────────┘
```

## ルール適用

- KPIカードは上位に、根拠チャートを下段に（dash-kpi-hierarchy）。
- 各要素に単位・期間・出典（dash-meta, `[自動]`）。
- 棒グラフは0起点（dash-axis）。色は意味を持って一貫（dash-color-meaning）。
- 地図の行政区域ポリゴンは国土数値情報規約を個別確認するまで使用しない。

## トークン

color.json の `dataViz.categorical` / `sequential` を系列色・地図階級色に使う。

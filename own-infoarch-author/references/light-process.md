# 小さな依頼での省略の規則

単発のチラシや告知のような小さな依頼では、6 段を簡略にしてよい。ただし**段 1（依頼を固める）と段 6（見直して渡す）は省かない**。

| 段 | 小さな依頼での扱い |
| --- | --- |
| 1 依頼を固める | 省かない。目的・行動・必須事項を書く |
| 2 target を決める | 承認済みの positioning が 1 つしか合わなければ、そのセグメントを選んで終わり |
| 3 選ぶ・削る | 一番のメッセージと CTA だけを書く（置かないなら no_cta） |
| 4 構造 | 媒体の型を 1 つそのまま使う |
| 5 文案 | 辞書の固定値の参照は省かない。文の推敲は 1 回 |
| 6 見直す | 省かない。`check` を緑にし、一番が最初の一目に入っているか確かめる |

小さな依頼でも、台本のファイルは作る（逆引きと期限の検査が、台本を前提にしているため）。

## 出典

- 省略の規則そのもの：出典なし・目安（実務家のはっきりした指針は見つからなかった。調査の推論）。

# 媒体：LP（1 ページの Web）

## 構成の型（出発点）

| 型 | 並び | 使う時 |
| --- | --- | --- |
| 結論から | benefit → proof → how → objection → cta | 読み手が自分の課題に気づいている |
| 課題から | problem → benefit → proof → how → cta | 読み手が課題に気づいていない |

- 最初の画面に、対象者の 1 位のメッセージと行動喚起の入口を置く。
- 行動喚起は最後に加え、長いページでは途中にも置いてよい。
- 証拠は効用の直後に置く。

## 器の目安

- セクションは 4〜7 個（出典なし・目安）。入らないメッセージは削る。

## よくある失敗

- 最初の画面を、会社紹介や抽象的なキャッチコピーで使い切る。
- 証拠を最後にまとめて置き、効用との結び付きが切れる。

## 出典

- 結論を先頭に置く：Nielsen Norman Group（https://www.nngroup.com/articles/how-users-read-on-the-web/）。
- 型（AIDA・PAS など）：実務家の慣行で、効果の比較は逸話の域（出典なし・目安）。

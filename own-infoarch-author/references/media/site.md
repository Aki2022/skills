# 媒体：複数ページのサイト

## 構成の型（出発点）

- ページごとに目的を 1 つにする（トップ・サービス紹介・事例・料金・お問い合わせ など）。
- ページの集合は、読み手の行動の順に並べる（知る → 比べる → 確かめる → 行動する）。
- ナビゲーションのラベルは、読み手が探す語で書く。同じ語を繰り返さない（「サービス」「サービス一覧」「サービス紹介」を並べない）。
- 各ページの先頭に、そのページの目的に合うメッセージを置く。サイト全体の 1 位は、トップの最初の画面に置く。

## よくある失敗

- 社内の組織や製品の分け方で、ページを分ける。
- すべてのページに同じメッセージを繰り返す。

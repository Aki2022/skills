# 段 2 target を決める

目的：この成果物が立つ positioning（セグメント 1 つ）と、届けたい相手（target）を決める。target が決まると、どの提供価値を言えるかとトーンが決まる。

## やること

1. `positioning-author positioning` で、承認済みの positioning（セグメントごとの id・隙間・同等であるべき点・所属カテゴリー）を見る。段 1 の行動を取る人のセグメントを**1 つ**選ぶ。
2. target を「セグメント（id）＋足す条件」で書く。足す条件で、ジョブや代替まで変わる相手なら、それは別のセグメントにすべき相手：作業を止め、positioning の追加をオーナーに提案する。
3. 払う人と使う人が違えば、別のセグメントで、別の outline・別の入口にする。1 つの成果物で両方に話さない。
4. その相手に向けたトーン（話し方の調子）を決める。トーンは成果物ごとに outline の `tone` が持つ。repo 全体の話し方の正典（声）は無い。
5. 承認の無い positioning には立てない。オーナーの承認が無い原子・矢印に立つと、出荷で止まる（IA_POSITIONING_UNAPPROVED・IA_OUTLINE_VALUE_UNAPPROVED）。

## よくある失敗

- 「全員向け」にする。言える提供価値が決まらず、段 3 で何も削れなくなる。
- target の条件を、セグメントを作り直すべき違いに使う（別のジョブを持つ相手を、条件だけで足す）。

## アウトラインへの書き方

`target`（`segment`・`condition`）・`tone`。

## 出典

- 一次の対象者を 1 人に絞る：コンテンツ戦略・クリエイティブブリーフの一般的な経験則（出典なし・目安。複数の実務家の説で一致するが、一次資料は確認していない）。
- トーンを相手と状況で変える：Mailchimp Content Style Guide（https://styleguide.mailchimp.com/voice-and-tone/）、Shopify Polaris（https://polaris.shopify.com/content/voice-and-tone）。

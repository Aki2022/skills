# Layout Grammar v3 — 基本型 × 修飾子

会社様式（test3.pptx 実測、2026-07-13 確定）を「**基本型 × 修飾子**」に圧縮した体系。

> **原則: この文法は「デフォルトの語彙」であって「檻」ではない。**
> Style DNA（色・トーン・ブランド、imagegen-prompt-convention.md参照）は常時適用するが、
> レイアウト制約はスライドの性格に応じて外してよい。型に無い構図（全面画像の印象重視スライド等）は
> **自由形（Free）** を使い、imagegenの創造力に構図を委ねる。

すべて **960×540pt（33.87×19.05cm、PowerPoint標準ワイド画面）** キャンバス基準。各型は2用途で使う:

1. **imagegen プロンプト**: 定性バンド記述（「上部の細いタイトル帯」「正確に3列」）＋明示的個数。
   ※ %座標は渡さない（モデルは数値座標を守らない。定性表現＋個数が最も遵守される）
2. **ネイティブ再現（PptxGenJS）**: 座標表のpt値をそのまま `x/y/w/h`（inch換算: pt÷72）に使う

## タイトルとキーメッセージの意味論（v3で最重要・全型共通）

| 要素                   | 意味                             | 規則                                                                                         |
| ---------------------- | -------------------------------- | -------------------------------------------------------------------------------------------- |
| **タイトル = tracker** | 今どの章にいるかを示す小さな道標 | **名詞句（章タイトル）or 疑問形**。例:「課題は？」「導入効果」。目立たせない（14pt・グレー） |
| **キーメッセージ**     | このスライドの主張               | **必ず1行**。タイトルが疑問形ならその**回答**。28pt・tone色                                  |

- **1スライド1メッセージ。** メッセージはキーメッセージ行だけに置く。
- **全スライドのキーメッセージを上から順に並べて読むと、それだけでストーリーとして成立**
  しなければならない（①outline確定時の必須チェック、pipeline.md参照）。

### 禁止事項（v3確定）

- **takeaway box 禁止**: スライド下段にまとめ・結論・メッセージの箱を置かない。
- **バンパーステートメント禁止**: 本文中に帯状の主張文を挟まない。
- 説明・詳細が必要な場合は (a) キーメッセージ直下の本文内で示す、(b) 長い場合は
  **右1/3を箇条書きセクション**にするレイアウト（ハイブリッド型）を使う。

## 修飾子（3軸）

### mode — 用途による密度

| mode                        | 構造                                                             | 密度                                 |
| --------------------------- | ---------------------------------------------------------------- | ------------------------------------ |
| **handout**（配布用・既定） | tracker＋**1行キーメッセージ**＋本文。読むだけで伝わる自己完結型 | 高（本文14pt）                       |
| **preso**（舞台用）         | tracker最小or無し、ビジュアル中心。喋りが主役                    | 低（文字量を半分以下に、余白を広く） |

### tone — キーメッセージの色調（test3.pptx実測・2026-07-13確定）

| tone                | 色                                     | 意味                     |
| ------------------- | -------------------------------------- | ------------------------ |
| **neutral**（既定） | `--color-message-neutral` **#404040**  | 中立・事実の提示         |
| **positive**        | `--color-message-positive` **#44546A** | 肯定的な主張・推奨       |
| **negative**        | `--color-message-negative` **#C00000** | 警告・課題・否定的な指摘 |

### content — プレースホルダーの中身

`text` / `object`（図解・フロー） / `chart`（→ chart-rules.md、実データは必ずネイティブ） / `table` / `picture`（image_gen文字なしアセット or 写真）

**指定例**: `単一 × handout × negative × chart` = 「tracker＋赤キーメッセージ＋ネイティブチャート1点」

## 共通要素（クローム層）— test3.pptx 実測（2026-07-13）

deck_helpers.js v3 の `defineSlideMaster` に集約済み。座標は tokens.json `chrome.*` が正典。

| 要素                 | 座標 (x, y, w, h) pt    | スタイル                                                                         |
| -------------------- | ----------------------- | -------------------------------------------------------------------------------- |
| タイトル（tracker）  | 12, 18.4, 936, 21.6     | 14pt（フォント=BIZ UDPGothic）、**#7F7F7F**、左揃え、行間90%                              |
| キーメッセージ       | 12, 39.7, 936, 64.9     | 28pt（フォント=BIZ UDPGothic）、**tone色**、左揃え、**上下中央(valign: middle)**、1行厳守 |
| 本文エリア           | 42, 110, 876, 390       | 型ごとに分割（下記）。最下端 y≤500pt                                             |
| フッター日付（左下） | 21, 512.8, 224, 25.5    | 12pt、**#D9D9D9**、下揃え（例: July 13, 2026）                                   |
| ページ番号（右下）   | 725.4, 512.8, 224, 25.5 | 12pt、**#D9D9D9**、右揃え・下揃え                                                |
| コピーライト（右端） | 953, 268, 7, 272        | 6pt、**#BFBFBF**、**縦書き(vert270)・下寄せ**。文言は tokens.chrome              |

**塗りつぶしタイトルバンドは存在しない**（生成時の頻出誤りとして明示的に禁止）。

**imagegen共通指示**: 「a SMALL gray tracker label top-left (chapter name or a short question);
below it ONE key-message line in {tone色} — if the tracker is a question this line answers it;
NO filled title band; NO takeaway box at the bottom; footer with small very-light-gray date
bottom-left and page number bottom-right; a tiny vertical copyright line on the right edge;
no element touches the frame edge」

## 基本型

### 1. 表紙 / Title

- **imagegen**: 「中央やや上に大きなタイトル（1〜2行）、下に小さくサブタイトル、下部に発行者・日付の一行。
  右側または背景に控えめなモチーフ。余白を贅沢に。グレー基調」
- **ネイティブ**: タイトル 80, 190, 800, 100（32pt #404040）/ サブタイトル 80, 310, 660, 40（18pt #7F7F7F）/ 発行者 80, 460, 800, 30（12pt #7F7F7F）

### 2. 目次 / Contents

- **imagegen**: 「左に『目次』見出し、番号付き項目を縦に4〜6行、各行は短い一句、行間広め」
- **ネイティブ**: 見出し 42, 110, 260, 50 / 項目リスト 80, 180, 800, 320（1項目高さ50pt、番号バッジ+テキスト）

### 3. セクション扉 / Section

- **imagegen**: 「章番号を大きく、章タイトルを中央に、ほぼ余白の静かな扉。装飾は最小」
- **ネイティブ**: 章番号 80, 160, 160, 80（32pt #BFBFBF）/ 章タイトル 80, 250, 800, 70（32pt #404040）
- 自由形に切り替えて印象的な扉にするのも推奨される使い方。

#### 3b. 現在地ナビ変種（本編10枚超のhandoutでは既定・2026-07-16 人間手直しデッキ実測）

各セクション冒頭に目次を再掲し、現在地だけを強調する章扉。①outline作成時に本編10枚超なら
既定でセクションごとに1枚提案する（北浦メディアデッキで人間が4枚手動追加した実績）。

- **imagegen**: 「左端にスライド全高の紺グレー #44546A 縦バンド（幅約20%、中に小さく
  『Contents』の白文字）。右側の薄グレー地に目次項目を縦一列・番号付きで再掲し、
  **現在のセクションのみ黒・太字・大きく**、他はグレー・細字・小さく。囲み枠・下線・
  背景色変化は使わない（色×太さ×サイズの3点のみで現在地を表現）」
- **ネイティブ（目安）**: 縦バンド rct 0, 0, 192, 540（#44546A塗り・枠線なし）＋「Contents」
  白14pt 縦中央 / 項目リスト x=260, 1項目高さ約90pt、番号+項目名。
  現在地=24pt bold #404040 / 他=16pt #BFBFBF
- 様式見本: `anchors/anchor_v3_agenda-nav.png`（人間手直しデッキ由来・承認済み）

### 4. 単一 / Single（content: text | object | chart | table | picture）

- **imagegen**: 「共通要素＋本文エリアに{content}を1点、キャプション任意」
- **ネイティブ**: 本文エリア 42, 110, 876, 390 に content を1点配置。
  - chart: chart-rules.md 準拠のネイティブチャート（画像化禁止）
  - table: tokens.json `table.*` 準拠（薄グレー罫線・panelヘッダー）。**表は必ず addTable で作る。枠線を画像で描かない**
  - object: 図解ノード＝panel塗り(F2F2F2)+枠線なし+濃グレー文字。強調ノードのみ #44546A（ネガ文脈 #C00000）塗り+白文字

### 5. 2列 / TwoCol

- **imagegen**: 「本文エリアを左右2等分、**正確に2つ**の同格ブロック。中央に細い区切りor余白」
- **ネイティブ**: 左 42, 110, 424, 390 / 右 494, 110, 424, 390
- 左右のcontentは独立指定可（text+chart 等 → ハイブリッド型を参照）

### 6. 3列 / ThreeCol（test3.pptx実測座標）

- **imagegen**: 「本文エリアに**正確に3つ**の等幅カードを横並び、等間隔。カードは極薄グレー角丸・枠線なし」
- **ネイティブ**: 列幅277pt、x = 42 / 341 / 640、y=102, h=247（カード内: アイコン上・見出し25pt bold 中央・本文14pt 中央）

### 7. 比較 / Comparison

- **imagegen**: 「2〜3列の対比構成。各列に見出し帯＋内容。対比軸が一目で分かるよう列見出しを強調。
  優劣・推奨があれば片方を #44546A で強調、他方をmuted」
- **ネイティブ**: TwoCol/ThreeCol座標＋各列上部に見出し帯（h=36pt、推奨列=#44546A塗り白文字、他列=panel F2F2F2）
- negative tone との組合せで「課題vs対策」等に使う。

### 8. ハイブリッド / ContentText（左メイン＋右1/3箇条書き）★説明が必要なときの標準解

- **用途**: キーメッセージだけでは足りず説明詳細が要るスライド。takeaway box の代わりにこれを使う。
- **imagegen**: 「左2/3に主たる{content}、**右1/3に箇条書き3〜4点**。テキストがcontentを解説する関係」
- **ネイティブ**: content 42, 110, 560, 390 / テキスト 630, 110, 288, 390（左右比率は2:1目安、逆配置も可）

#### 右カラム箇条書きのスタイル規則（2026-07-16 人間手直しデッキ実測で改訂）

一律14ptは「小さすぎ・強弱がない」として人間に全面手直しされた実績がある。以下を既定とする:

- **フォントは項目数でスケール**: 2〜3項目=**20pt** / 4項目=**18pt** / 5項目以上=14pt
  （項目が少ないほど大きく。実測: 3項目→20pt・4項目→18pt・5項目→14pt維持）
- **結論行の格上げ**: 最も伝えたい一文はマーカーを外し、**太字の独立パラグラフ**として置く
- **示唆ボックス（許可される装置）**: 右カラム下部に「白地＋黒細枠＋太字 #44546A」の囲みで
  気づき・示唆を1つ置いてよい。※スライド**全幅**のtakeaway box禁止は従来通り（右カラム内限定）
- マーカー形状（●/■/・）・字下げ・区切り線・カラム位置は従来仕様のまま変えない
- 様式見本: `anchors/anchor_v3_contenttext-insightbox.png`（18pt箇条書き＋示唆ボックス）

### 9. 自由形 / Free ★創造性の逃げ道

- **用途**: 全面画像の印象重視スライド、コンセプトビジュアル、表紙・扉の意欲作、型に収まらない図解
- **imagegen**: レイアウト指示を最小化し、**Style DNAとスライドの意図（伝えたい感情・メッセージ）だけを渡す**。
  構図はモデルに委ねる。「16:9、余白の確保、日本語テキストは最小限」のみ制約
- **ネイティブ再現**: 承認モックアップを仕様として個別に組む（座標表なし）。
  全面ビジュアルの場合は「背景=画像アセット＋前景テキストのみネイティブ」の構成も許容
  （テキストの編集可能性だけは常に確保する）
- **検収**: ブランド適合（色・トーン）のみチェック。レイアウト規則は適用しない

## テキストの組み方（v3規則）

- **改行**: 自動折返しに任せず、**文節境界に手動改行（`\n` / breakLine）** を入れて自然に読めるようにする。
- **配置**: `valign: "middle"` / `align: "center"` を意識的に指定する。カード見出し・数値・バッジは中央、
  本文ブロックは上揃えが既定。
- **数字と単位**: 単位は数字の**50%サイズ**。同一テキストボックス内のラン混在で組む
  （deck_helpers.js `numUnit` ヘルパ: 数値20pt bold + 単位10pt bold）。
- **オブジェクト**: できるだけPowerPoint標準プリセット図形（roundRect・rightArrow・homePlate等）を使い、
  単体で無理な形は標準図形の組み合わせで作る。枠線・区切り・表を画像で描かない。

## テキスト量目安（imagegen・ネイティブ共通）

| 要素                   | 上限                                                    |
| ---------------------- | ------------------------------------------------------- |
| タイトル（tracker）    | 15字×1行（名詞句 or 疑問形）                            |
| キーメッセージ         | **33字**×1行厳守（34字以上は28ptで折返す。gotchas §18） |
| 図解ノード見出し       | 8字                                                     |
| ノード補足・カード本文 | 14字×2行                                                |
| 箇条書き本文           | 40字×2行、項目3〜5個                                    |
| 列見出し               | 10字                                                    |

imagegen モックアップ内の日本語は構図確認用の近似でよい（正確な字形は不要）が、**個数と行数は正確に**
（後のネイティブ再現でテキストが収まるかの事前検証を兼ねるため）。
